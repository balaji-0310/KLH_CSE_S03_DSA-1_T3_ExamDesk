## 5. Abstract
ExamDesk is a project designed to make the exam process easier and more organized. It helpsmanage student attendance, distribute answerscripts
to evaluators, detect copying, and publishstudent results in rank order. The project uses different Data Structures and Algorithms
concepts such as Hashing, Counting, Dynamic Programming, Prefix Sums, String Matching(KMP), and Searching. These concepts help process
information, reduce repeated work, andmake result preparation more efficient. The main aim of ExamDesk is to make exam
management simple, fast, and reliable
